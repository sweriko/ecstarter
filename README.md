# Three.js + Rapier + bitECS Starter

Minimal starter for 3D browser games using Entity Component System architecture.

## Setup

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

## Core Architecture

- **ECS**: Entity-component-system using [bitECS](https://github.com/NateTheGreatt/bitECS)
- **3D**: [Three.js](https://threejs.org/) for rendering
- **Physics**: [Rapier](https://rapier.rs/) for 3D physics simulation
- **Bundling**: Vite with TypeScript support


## Key Features

- First-person controller with character controller
- Physics-based shooting with collision detection
- Continuous collision detection for fast objects
- Debug visualization tools
- Performance monitoring
